# 错词本背单词（本地优先 PWA）

以「错词本」为核心机制的背单词软件。**手机端背诵，电脑端导入/导出/打印**，数据全部存在本机浏览器（IndexedDB），零成本、可离线、不依赖任何云端账号。

> 参考《扣子智能体开发需求文档_错词本背单词软件》的功能需求实现；因你要求「不考虑扣子部署、本地优先」，后端改为浏览器本地存储，跨设备同步通过「导出 / 导入 JSON 文件」完成。

## 一、本地运行

1. 双击 `start.bat`（需本机已装 Node.js 或 Python）。
2. 浏览器打开 `http://localhost:8080`。
3. 手机端：让手机和电脑连同一 Wi-Fi，用电脑局域网 IP 访问 `http://<电脑IP>:8080`；或在手机浏览器打开后点「添加到主屏幕」即可像 App 一样全屏使用。

> 不通过 http 直接双击 `index.html`（file://）会因浏览器安全策略禁用 IndexedDB 与 Service Worker，请务必用上面的本地服务方式打开。

## 二、手机端（核心使用）

1. **词库**：打开即见已导入词库；点词库进入背诵。
2. **背诵设置**：选分组范围（多选，不选=全部；分组多时可用「全选 / 清空」一键操作）、学习范围（全部 / 仅错词）、顺序 / 随机、记英文 / 记中文。
3. **背诵页**：显示单词（或释义），点 🔊 听标准发音；答错点「❌ 标记错误」（错误次数 +1 并弹出错词卡，含例句），答对点「✓ 下一个」；顶部进度条。
4. **统计**：当前词库错词数、各分组错误率、错词排行榜。

## 三、电脑端（导入 / 导出 / 打印）

- **导入词库**：支持 `.xlsx / .xls / .csv / .txt` 与直接粘贴文本。
  - 中考1600词格式：4 列（Unit / 序号 / 单词 / 词义），自动跳过前 3 行、Unit 前向填充、group_tag 规范为 `Unit1` 等。
  - 通用格式：至少含「英文单词」「中文释义」两列，可选「分组标记」「序号」「例句」。
  - 列分隔符自动识别（制表符 / 逗号 / 分号 / 竖线）。
- **导出数据**：选词库、格式（CSV / JSON）、范围（全部 / 仅错词）、排序（词序 / 错误数 / 分组），点「导出下载」。CSV 带 UTF-8 BOM，Excel 直接打开不乱码。
- **打印 / 存 PDF**：选词库与范围，点「打印 / 存为 PDF」，在打印对话框选「目标 = 另存为 PDF」即可导出单词表 PDF。
- **数据看板**：各词库词数、错词数、错误总次数，及完整单词明细表。

## 四、跨设备同步

本地优先方案下，跨设备同步 = 文件同步：

1. 在设备 A 的「管理」页导出 JSON（含错误次数）。
2. 把 JSON 传到设备 B，在「导入词库」里选该文件（或粘贴），即完成同步。
   - 提示：导入时若词库名相同会新建一份；如需覆盖，先在设备 B 删除旧词库再导入。

## 五、部署到公网（手机可「添加到主屏幕」）

PWA 需 HTTPS 托管才能安装到手机桌面。把整个 `vocab-app` 文件夹推到 GitHub Pages / Netlify / Vercel 等静态托管即可，零成本：

- GitHub Pages：新建仓库 → 上传本文件夹 → Settings → Pages → 选 main 分支根目录 → 访问生成的 `https://<用户名>.github.io/<仓库>/`。
- 手机打开该地址 → 浏览器菜单「添加到主屏幕」。

## 六、文件说明

| 文件 | 作用 |
|---|---|
| `index.html` | 应用主体（内联 CSS + JS） |
| `core.js` | 导入解析 / 导出 纯逻辑（可被 Node 单元测试） |
| `manifest.json` / `sw.js` / `icon.svg` | PWA 配置与离线缓存 |
| `libs/xlsx.full.min.js` | 本地解析 xlsx（离线可用） |
| `server.js` / `start.bat` | 零依赖本地启动服务 |
| `sample_zhongkao1600.xlsx` / `sample_通用词库.csv` | 测试用样本词库 |
| `wordlibs/real_中考1600词.xlsx` | 你提供的真实词库（1600 词 / 160 单元），可直接导入 |
